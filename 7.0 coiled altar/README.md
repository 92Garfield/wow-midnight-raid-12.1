# Coiled Altar

## Phase 1
- Collect green orbs
  - Group them up - assign 2 players
  - Blow them up with the tank frontal
  - (HC) Raid DoT per orb
- Group soak on the edge
  - Run away from the AoE after
  - (HC) 2 groups alternate

## Phase 2 - Zuljan dead
- (HC) Assign 3 (ranged) players to interrupt the add 👹
- Purple circles around players
  - Get out of the raid
  - When it elapses, collect 3 souls (check the debuff)
- MC'd players try to jump off the platform
  - Break the shield to free them
  - Freed players spawn 2 ghosts
    - Ghosts fixate random players
    - Ghosts stop moving while looked at
    - Destroy with the tank frontal
- Destroy the boss shield, kick the cast

## Intermission ⏸️ - Malacross dead
- 🎯 Damage amp + 100% - hit Zuljan

## Phase 3 - time based
- Phase 1 + Phase 2
