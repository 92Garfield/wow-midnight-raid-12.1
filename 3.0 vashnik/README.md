# Vashnik

- Adds 👹 move to the center — priority
- One debuff per color
- 2 altars activate at a time
  - On the 2nd activation in a row, the altar is empowered

## 🔴 Red — Blood
- 👹 Add
  - ❄️ CC immune
  - Splits into 2 on kill
- Debuff
  - Heal absorb
  - Soaks from players around the affected (Miasma, Hungering Destroyer)

## 🟠 Orange — Fire
- 👹 Add
  - Spawns 2
  - Pulsing damage while alive
  - Debuff on the raid when killed — ❓ stackable
- Debuff
  - Falloff damage from the player

## 🔵 Blue — Shadow
- 👹 Add
  - Multiple, ❄️ CC-able
  - Spawns impact when killed
- Debuff
  - Spawns impact below the player
